# chemistry-lab

A fun, beautiful, and interactive virtual science lab built for kids! It combines colorful chemical animations with simple science lessons using a cozy, frosted-glass design.

---

##  What Experiments Can You Do?

* ** The Volcano:** Mix baking soda and vinegar to watch carbon dioxide gas bubble up and fill the beaker!
* ** The Geyser:** Drop candy into a bottle of soda and watch the trapped gas instantly erupt out.
* ** Disappearing Act:** Drop salt crystals into water and watch them sink, settle, and slowly melt away into invisible ions.
* ** Magic Color Potion:** Add lemon juice (acid) or soap (base) to see a magical purple potion smoothly change into bright pink or green.
* ** Color Clearing:** Mix a dark purple chemical with peroxide to strip its color away, turning it back into clear water with tiny oxygen bubbles.

---

##  How It's Built

* **Design:** Built using **Tailwind CSS** for a gorgeous pastel look, complete with floating emojis and glass cards.
* **Animations:** Uses a native **HTML5 Canvas** system to make liquids rise, change colors smoothly, and shoot realistic bubbles.
* **Clean Code:** Every experiment is neatly packaged inside its own little codebase block, making it super easy to add new reactions later.

---

##  How to Run It

1. Save the code into a file named `index.html`.
2. Double-click the file to open it in **any web browser** (like Chrome, Safari, or Edge).
3. No setup, internet servers, or installations required!
